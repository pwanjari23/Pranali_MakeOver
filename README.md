# Pranali Beauty Parlour & Makeover Academy

A luxury, high-fashion frontend website for **Pranali Beauty Parlour**, showcasing bespoke bridal couture makeovers, celebrity styling, luxury salon care, and the **Pranali Makeover Academy** in Pune, Maharashtra.

## ✨ Features
- **Editorial Beauty Aesthetics**: Warm espresso (`#14110F`) and champagne gold palette inspired by luxury beauty magazines.
- **Typography**: Paired serif headings (*Cormorant Garamond*) with modern geometric sans-serif (*Plus Jakarta Sans*).
- **Mobile-First UX Optimization**: Touch-friendly horizontal swipe snap-rails for services, portfolio, and courses, reducing vertical scroll fatigue by ~65%.
- **Mobile Quick-Dock**: Translucent bottom dock for 1-tap navigation and instant WhatsApp appointment requests.

## 🛠️ Tech Stack
- React 19 (Vite)
- Tailwind CSS
- Framer Motion
- Lucide React

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/pwanjari23/Pranali_MakeOver.git

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
